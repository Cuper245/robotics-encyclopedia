    How I approach a problem

    Before writing a single line of code, the process always goes through three stages:

    1. Understand the problem Read it carefully. Identify what the output should be, what the input is, and what formulas or conditions are involved. Design test cases before coding.

    2. Design a solution Identify the calculations, conditions, and repetitions needed. Think about whether there's a more efficient way to do it. Build the design (flowchart or pseudocode), then test it with the test cases from step 1.

    3. Test the design Use the test cases. A good algorithm is complete (works for all cases), unambiguous, and finite.

    Test cases

    The idea is to identify the minimum set of inputs that verify the program works in every scenario.

    For a range of values — test the boundary values: a-1, a, b, and b+1 where [a, b] is the valid range.

    For a set of values — test one value inside the set and one outside.

    For a repetition — test: zero iterations (if it makes sense), once, twice, and more than twice.

    A test case has: input data + expected result.

    Problem: check if a price is valid (positive only)
Test 1: input = -20  → Not valid
Test 2: input = 35   → Valid
Test 3: input = 0    → Not valid

    Python coding conventions (PEP 8)

    The rules I need to remember when writing clean code:

    • Variable and function names: lowercase with underscores — student_name, days_worked
    • Constants: UPPERCASE with underscores — MAX_EMPLOYEES, GRAVITY
    • Max line length: 79 characters — break long lines with \ or parentheses
    • Indentation: 4 spaces (never tabs)
    • One statement per line
    • All functions must have a docstring
    def speed(distance, time):
    """Calculate speed from distance and time."""
    return distance / time
    • Don't use l, O, or I as single-character variable names — they look like 1 and 0

    Arithmetic expressions

    Python operator precedence (high to low):

    Operator Description
    ** Exponentiation
    -x Unary negation
    * / // % Multiplication, division, floor division, modulo
    + - Addition, subtraction 
     4 + 7 / 2 - 5 * 3     # = -7.5   (division before addition)
 6 / 4 + 5 % 3 + 8 // 3 # = 5.5

    Key distinction:

    • / → true division, always returns float: 7 / 2 = 3.5

    • // → floor division, truncates: 7 // 2 = 3

    • % → modulo, remainder: 7 % 2 = 1

    math library

     import math

 math.sin(math.radians(30))  # convert degrees to radians first
 math.sqrt(25)               # 5.0
 math.pi                     # 3.14159...
 math.e                      # 2.71828... (Euler's number)
 math.trunc(3.9)             # 3 (truncates, doesn't round)
 math.floor(3.9)             # 3
 math.ceil(3.1)              # 4

    Boolean expressions

    Comparison operators return True or False:

     ==   !=   >   <   >=   <=

    Logical operators: 

     and   or   not


     (3.0 * -2 > -10) and (5 * 4 == 15)   # False (second part is False)
 (5 * 3.0 != 9) or (10 // 3 > 3)      # True (first part is True)
 not (5 != 8) or (3.0 >= 3)            # True
 ('h' == 'H') or ('c' > 'a')           # True (char comparison is case-sensitive)

    Decision statements

     if condition:
     # do this
 elif other_condition:
     # do this instead
 else:
     # fallback

    Important: if chains vs independent ifs behave differently.

     # This checks all three independently
 if x > 2:
     print(x)
 if y < 5:
     print(y)
 if x <= 5 and y >= 5:
     print(x + y)

 # This stops at the first True
 if x > 5:
     print(x)
 elif y < 5:
     print(y)
 else:
     print(x + y)

    Functions

     def function_name(param1, param2):
     """Brief description of what this does."""
     result = param1 + param2
     return result

    Key things to remember:

    • Parameters are local — changing them inside the function doesn't affect the original variable outside
    • A function can return multiple values: return a, b
    • If no return, the function returns None
     def is_leap(year):
     """Return True if year is a leap year, False otherwise."""
     if year % 400 == 0:
         return True
     elif year % 100 == 0:
         return False
     elif year % 4 == 0:
         return True
     else:
         return False

    Repetition

    for loop

     for var in range(start, stop, step):
     # body

    range is exclusive at the end — range(2, 10) goes 2, 3, 4 ... 9.

     for a in range(2, 10):      # 2 to 9
     print(a)

 for b in range(10, 1, -2):  # 10, 8, 6, 4, 2
     print(b)

 for c in range(0, 60, 11):  # 0, 11, 22, 33, 44, 55
     print(c)

    while loop

     x = 7
 while x >= 0:
     print(x)
     x -= 2      # 7, 5, 3, 1

    Converting for → while: 

     # for version
 for var in range(3, 15, 4):
     print(var)

 # equivalent while version
 cont = 3
 while cont < 15:
     print(cont)
     cont += 4

    Nested loops

     for h in range(2, 4):       # h = 2, 3
     for i in range(1, 5):   # i = 1, 2, 3, 4
         print(h, i)
 # prints: 2 1 / 2 2 / 2 3 / 2 4 / 3 1 / 3 2 / 3 3 / 3 4

    Pygame basics

    Pygame was used to build a simple game project. The key structure:

     import pygame, sys

 pygame.init()

 # Screen
 size = (500, 800)
 screen = pygame.display.set_mode(size)

 # Clock (control FPS)
 clock = pygame.time.Clock()

 # Constants
 BLACK = (0, 0, 0)
 WHITE = (255, 255, 255)
 RED   = (255, 0, 0)
 BLUE  = (0, 0, 255)

 # Initial state
 coord_x = 0
 coord_y = 0
 vel_x = 3
 vel_y = 3

 # Main loop
 while True:
     for event in pygame.event.get():
         if event.type == pygame.QUIT:
             sys.exit()

     # Game logic (update state before drawing)
     coord_x += vel_x
     coord_y += vel_y

     # Bounce off walls
     if coord_x < 0 or coord_x > size[0]:
         vel_x *= -1
     if coord_y < 0 or coord_y > size[1]:
        vel_y *= -1

     # Draw
     screen.fill(WHITE)
     pygame.draw.circle(screen, BLUE, [coord_x, coord_y], 10)

     # Refresh
     pygame.display.flip()
     clock.tick(60)

    Screen coordinate system: origin (0,0) is top-left. X increases right, Y increases down.

    Collision detection:

     # Rect vs point
 collide = rect.collidepoint(pygame.mouse.get_pos())

 # Rect vs rect
 collide = rect1.colliderect(rect2)

 # Sprite collision
 pygame.sprite.collide_rect(sprite1, sprite2)
 pygame.sprite.collide_circle(sprite1, sprite2)
